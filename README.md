# Sales Dashboard using Power BI

## Project Overview
This project analyzes sales data using Power BI and presents key business insights through interactive visualizations.

## Features
- Total Sales KPI
- Product-wise Sales Analysis
- Monthly Sales Trend
- Sales & Profit Distribution

## Tools Used
- Power BI
- CSV Dataset

## Insights
- Laptop generated the highest sales.
- Total sales reached 220K.
- Monthly sales trends were visualized for business analysis.
